# Vizzo Homebrew tap

Installs [Vizzo](https://heyvizzo.com) on macOS 13 or later, Apple silicon only.

```sh
brew install heyvizzo/app/vizzo
```

Upgrade with `brew upgrade vizzo`. Remove the app with `brew uninstall vizzo`, or `brew uninstall --zap vizzo` to also delete its settings and downloaded speech models.

The source and the DMGs live at [heyvizzo/vizzo](https://github.com/heyvizzo/vizzo); this repo only holds the cask.
